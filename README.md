# project
**Мої активні проекти та інструменти**

**Веб-сервер:** нотатник і файлове сховище.
**Інструменти Windows:** віджет часу, утиліта для трею, менеджер буферу обміну, макроклавіатура, зміна MAC-адреси.
Системне адміністрування: віртуальні машини, скрипти, Docker (Ubuntu).
Апаратні проекти: Arduino, Home Assistant, медіаплеєр для ТВ.

**Os Meus Projetos Ativos e Ferramentas**

**Servidor Web:** bloco de notas e armazenamento de ficheiros.

**Ferramentas para Windows:** widget de tempo, utilitário para a área de notificação, gestor de área de transferência, teclado de macros, alteração de endereço MAC.

**Administração de sistemas:** máquinas virtuais, scripts, Docker (Ubuntu).

**Projetos de hardware:** Arduino, Home Assistant, media player para TV.
