# project
**Home budget** — Ordner für die Verwaltung von finanziellen Haushaltsdaten (Папка для управління даними сімейного бюджету).

**ClipboardEditor.exe** — Ein Programm zur Bearbeitung des Inhalts der Zwischenablage (Програма для редагування вмісту буфера обміну).

**Keyboard.exe** — Eine Anwendung zur Steuerung oder Konfiguration der Tastatur (Додаток для керування або налаштування клавіатури).

**MacChanger.exe** — Ein Tool zum Ändern der MAC-Adresse des Netzwerkadapters (Інструмент для зміни MAC-адреси мережевого адаптера).

**PrintWatcherUtility.exe** — Ein Dienstprogramm zur Überwachung von Druckaufträgen (Утиліта для моніторингу завдань друку).

**Prog_clock.exe** — Eine Anwendung, die eine Uhrzeit- oder Zeitsteuerungsfunktion bereitstellt (Додаток, що надає функцію годинника або таймера).

**README.md** — Eine Textdatei mit Informationen und Anweisungen zum Projekt (Текстовий файл з інформацією та інструкціями до проєкту).

**TrayLauncher.exe** — Ein Programm zum Starten von Anwendungen aus dem Infobereich der Taskleiste (Програма для запуску додатків із системного трею).

**apps.txt** — Eine Textdatei, die wahrscheinlich eine Liste von Anwendungen oder Konfigurationen enthält (Текстовий файл, що містить список додатків або конфігурацій).

**cast_server.py** — Ein Python-Skript für einen Server zum Streamen oder Übertragen von Medien (Python-скрипт для сервера трансляції або передачі медіа).

**youtube_downloader_gui.py** — Ein Python-Programm mit grafischer Benutzeroberfläche zum Herunterladen von YouTube-Videos (Python-програма з графічним інтерфейсом для завантаження відео з YouTube).
